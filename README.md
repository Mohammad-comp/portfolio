# Mohammad Abdullah | Portfolio

This is my personal portfolio website built for my web development coursework.

The website highlights my background, skills, education, experience, and projects as a Computer Science student.

## Features

- Responsive single-page layout
- About Me section
- Skills section
- Education section
- Experience section
- Projects section
- Contact links
- Resume download/view button
- GitHub and LinkedIn links

## Built With

- HTML
- CSS
- Font Awesome
